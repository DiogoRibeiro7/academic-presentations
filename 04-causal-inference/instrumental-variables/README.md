# instrumental-variables

## Overview

This topic develops instrumental-variable methods for causal inference under endogeneity, with emphasis on identification, two-stage least squares, weak instruments, heterogeneous treatment effects, and diagnostic reasoning.

## Scope

- sources of endogeneity;
- valid instrument conditions;
- first stage and reduced form;
- Wald estimator;
- two-stage least squares;
- Local Average Treatment Effects;
- monotonicity and compliers;
- weak-instrument bias;
- first-stage diagnostics;
- overidentified models;
- exclusion-restriction reasoning;
- sensitivity and falsification strategies.

## Design principle

An instrument is credible because of a substantive assignment mechanism, not because it predicts treatment strongly. Relevance is testable; exclusion and independence require scientific justification.
