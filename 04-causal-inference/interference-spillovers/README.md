# interference-spillovers

## Overview

This topic develops causal inference when one unit's treatment can affect another unit's outcome. It focuses on interference, spillovers, exposure mappings, cluster-randomized designs, network effects, and estimands beyond the classical no-interference setting.

## Scope

- SUTVA and the no-interference assumption;
- direct, indirect, spillover, and total effects;
- exposure mappings;
- partial interference;
- cluster-level randomized designs;
- network interference;
- saturation designs;
- two-stage randomization;
- contamination and displacement;
- design-based diagnostics;
- external validity and policy interpretation.

## Design principle

When interference is present, the treatment assignment vector matters. The causal estimand must specify not only whether a unit is treated, but also how other units are treated and connected.
