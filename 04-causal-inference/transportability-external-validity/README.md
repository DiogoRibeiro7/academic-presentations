# transportability-external-validity

## Overview

This topic develops transportability and external validity in causal inference: when, why, and how an effect estimated in one population, site, time period, or experiment can inform decisions in another.

## Scope

- internal validity versus external validity;
- target populations and study populations;
- effect modification;
- covariate shift and support;
- reweighting and standardization;
- transport formula intuition;
- site heterogeneity;
- trial-to-target generalization;
- deployment shift;
- temporal drift;
- policy and implementation differences;
- sensitivity to unmeasured effect modifiers.

## Design principle

A causal effect is not automatically portable. Transport requires assumptions about which mechanisms are stable, which effect modifiers are measured, and whether the target population has support in the original study data.
