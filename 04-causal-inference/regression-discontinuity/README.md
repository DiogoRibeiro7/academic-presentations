# regression-discontinuity

## Overview

This topic develops regression discontinuity designs for causal inference when treatment assignment changes at a known threshold.

## Scope

- running variables and cutoffs;
- sharp and fuzzy RDD;
- local causal estimands;
- continuity assumptions;
- bandwidth choice;
- local linear regression;
- polynomial pitfalls;
- manipulation and sorting around the cutoff;
- density tests;
- covariate balance;
- placebo cutoffs;
- robust bias-corrected inference;
- external-validity limits.

## Design principle

RDD identifies a local causal effect by comparing units just on either side of a treatment threshold. Credibility depends on continuity and the absence of precise manipulation near the cutoff.
