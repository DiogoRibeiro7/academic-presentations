# difference-in-differences

## Overview

This topic develops Difference-in-Differences and event-study designs for policy evaluation and observational causal inference.

## Scope

- canonical 2x2 Difference-in-Differences;
- potential-outcomes formulation;
- parallel-trends identification;
- two-way fixed-effects regression;
- event-study coefficients;
- anticipation and dynamic treatment effects;
- staggered treatment adoption;
- heterogeneous treatment effects;
- comparison-group choice;
- clustered uncertainty;
- placebo dates and falsification;
- limitations of pre-trend testing.

## Design principle

Difference-in-Differences identifies a causal effect from changes over time only when the untreated counterfactual trend is credible. The regression form does not create that counterfactual by itself.
