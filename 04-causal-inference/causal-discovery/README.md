# causal-discovery

## Overview

This topic develops causal discovery as a set of methods for learning causal structure from data under explicit assumptions.

## Scope

- directed acyclic graphs;
- Markov and faithfulness assumptions;
- d-separation and conditional independence;
- Markov equivalence classes;
- constraint-based discovery;
- score-based discovery;
- functional causal models;
- LiNGAM-style assumptions;
- latent confounding;
- interventions and invariance;
- validation, failure modes, and limits.

## Design principle

Causal discovery is not assumption-free causal inference. Algorithms can propose structures only relative to assumptions about the data-generating process, measurement, interventions, hidden variables, and statistical reliability.
