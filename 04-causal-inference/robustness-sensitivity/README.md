# robustness-sensitivity

## Overview

This topic develops robustness and falsification strategies for causal inference, with emphasis on placebos, negative controls, specification stability, sensitivity analysis, and transparent reporting of identification uncertainty.

## Scope

- placebo treatment dates, units, and outcomes;
- negative-control exposures and outcomes;
- pre-trend and balance falsification;
- specification curves and multiverse analysis;
- sensitivity to unmeasured confounding;
- overlap and trimming sensitivity;
- leave-one-cluster and leave-one-donor diagnostics;
- identification uncertainty.

## Design principle

Robustness checks should target plausible failure modes of the identifying design. Passing many irrelevant checks is less informative than failing one diagnostic that directly challenges a key assumption.
