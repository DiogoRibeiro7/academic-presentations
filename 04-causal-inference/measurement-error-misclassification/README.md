# measurement-error-misclassification

## Overview

This topic develops causal inference when treatment, outcome, confounders, mediators, or timing variables are measured with error or misclassified.

## Scope

- classical measurement error;
- differential and nondifferential misclassification;
- treatment misclassification;
- outcome misclassification;
- covariate measurement error;
- regression dilution;
- residual confounding from noisy covariates;
- validation samples;
- regression calibration;
- SIMEX;
- quantitative bias analysis;
- sensitivity analysis.

## Design principle

Measurement error changes the observed causal problem. Bias direction depends on which variable is mismeasured, whether the error is differential, and how the measurement process relates to treatment and outcome.
