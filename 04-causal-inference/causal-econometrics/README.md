# causal-econometrics

## Overview

This topic develops causal inference from an econometric perspective, with emphasis on identification, panel and longitudinal data, endogeneity, quasi-experimental designs, counterfactual construction, diagnostics, and uncertainty.

## Planned lecture sequence

1. Causal Econometrics: From Prediction to Identification
2. Panel Data, Fixed Effects, and Unobserved Heterogeneity
3. Difference-in-Differences and Event Studies
4. Instrumental Variables, Endogeneity, and 2SLS
5. Counterfactual Time-Series Methods
6. Selection on Observables and Doubly Robust Estimation
7. Dynamic Treatment Effects
8. Robustness, Placebos, Negative Controls, and Sensitivity Analysis

## Design principle

Every analysis should state the estimand, identification assumptions, estimator, diagnostics, uncertainty, and limitations explicitly.
